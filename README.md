# Portafolio de Laboratorios - ADSO Java

Repositorio oficial para el almacenamiento y gestión de las evidencias prácticas del proceso formativo en Java.

## 📂 Estructura del Repositorio
- `laboratorio-01/`: Contiene los scripts iniciales de variables, operadores, lectura de datos y el reto de cotización de compras.
- `laboratorio-02/`: Contiene los ejercicios de estructuras de control (condicionales, ciclos), validaciones y el desarrollo de la Billetera en Consola utilizando métodos estáticos.

## 🚀 Instrucciones de Ejecución
1. Asegúrate de tener instalado el **JDK de Java** en tu equipo.
2. Ingresa a la carpeta del laboratorio que deseas ejecutar.
3. Compila el archivo fuente de tu interés:
   ```bash
   javac NombreArchivo.java
