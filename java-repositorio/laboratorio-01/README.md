\# Laboratorio 1: Primeros pasos con Java



Repositorio personal para almacenar las prácticas iniciales del proceso formativo en ADSO.



\## Estructura de la carpeta

\- `laboratorio-01/`: Contiene todos los scripts desarrollados para la práctica de variables, operadores, entradas de usuario y el reto integrador (`CotizadorCompra.java`).



\## Cómo ejecutar los programas

1\. Asegúrate de tener instalado el \*\*JDK de Java\*\* (versión 21 recomendada).

2\. Abre la terminal en la carpeta del archivo fuente (`.java`).

3\. Compila el archivo ejecutando:

&#x20;  ```bash

&#x20;  javac NombreArchivo.java
